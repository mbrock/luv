# Knuth book-design reference set

Private visual-study set assembled 29 August 2026. All images are page
rasterizations from files that Donald Knuth publishes from his Stanford site.
The selection is intentionally small: it is for studying composition, not for
substituting for the books.

Knuth's official TAOCP page, which links the source files and explicitly invites
readers to alpha-test the pre-fascicles, is
<https://www-cs-faculty.stanford.edu/~knuth/taocp.html>.

Exact source: <https://www-cs-faculty.stanford.edu/~knuth/fasc8a.ps.gz>
(official compressed PostScript; rasterized locally without editorial changes).

- `hamiltonian-pdf28-printed22-m-configs.png` — source PDF page 28,
  printed page 22, §7.2.2.4, the five 2-configs of Hamilton's graph. Useful for
  the easy alternation of prose, a short display, and a wide family of tiny
  diagrams that remains readable without boxes.
- `hamiltonian-pdf30-printed24-algorithm-e.png` — source PDF page 30,
  printed page 24, §7.2.2.4, correspondence (33) and trie representation for
  Algorithm E. Useful for mathematical exposition that moves from a displayed
  relation into a data-structure picture while marginal index cues form a quiet
  second column.
- `hamiltonian-pdf100-printed94-visual-answer.png` — source PDF page 100,
  printed page 94, Answers to Exercises for §7.2.2.4. Useful as an extreme
  example of a full-page visual algorithm/result: dense symbolic texture,
  controlled whitespace, and a tiny amount of navigational furniture.
- `hamiltonian-pdf106-printed100-matrix-panels.png` — source PDF page 106,
  printed page 100, Answers to Exercises for §7.2.2.4. Useful for its four-up
  comparison of matrices/patterns and the way labels, arrays, and a historical
  note share one baseline system.

the pre-fascicle available for reader checking, not under an open-content

## Design observations for the Luv wiki

1. **A narrow semantic margin beats decorative furniture.** Running section
   data and index cues stay peripheral, leaving one strong reading column.
2. **Diagrams participate in the prose rhythm.** They arrive immediately after
   their rule or definition and use the same symbols, type scale, and alignment.
3. **Comparison is spatial.** Repeated states, matrices, or alphabets use a
   stable grid rather than repeated prose or card borders.
4. **Density needs landmarks, not more boxes.** Equation numbers, figure labels,
   short headings, and generous breaks make very dense pages navigable.
5. **Technical pages can have a visual climax.** One large tree, flowchart, or
   patterned answer gives a spread identity; surrounding text stays restrained.
6. **Spot color is structural.** In the brochure and dissection examples, color
   distinguishes systems or parts instead of decorating headings.
7. **Typographic algorithms can stay typographic.** Flowcharts and tables use
   rules and arrows sparingly; labels and whitespace carry hierarchy.
