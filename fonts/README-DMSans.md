DM Sans regular and bold are bundled from Google Fonts' original static release:
https://github.com/googlefonts/dm-fonts/tree/main/Sans/Exports

Source files: DMSans-Regular.ttf, DMSans-Bold.ttf (version 1.200).
License: SIL Open Font License, included as LICENSE-DMSans.txt.

The static TrueType outlines work with the same Slug/TrueType loading and
measurement path as the existing bundled fonts; no runtime font download.
